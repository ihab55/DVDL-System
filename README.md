  <h1 style="color: #0a66c2; font-size: 24px;">🚀 Excited to Share My DVLD (Driver's License System) Project! 🚀</h1>
  
  <p>I recently completed a comprehensive <strong>Driver's License and Vehicle Licensing Division (DVLD) System</strong> built with <strong>C# .NET (Windows Forms)</strong>. This project simulates a real-world system for managing driver's licenses, applications, tests, and more.</p>
  
  <h2 style="color: #0a66c2; font-size: 20px;">🔹 Key Features:</h2>
  
  <ul style="padding-left: 20px;">
    <li>✅ <strong>User Management:</strong> Secure login, password changes, and user role handling.</li>
    <li>✅ <strong>All Objects:</strong> CRUD operations.</li>
    <li>✅ <strong>License Services:</strong>
      <ul style="padding-left: 20px;">
        <li>- New local/international license applications</li>
        <li>- License renewal and replacement for lost/damaged licenses</li>
        <li>- Detain and release licenses</li>
      </ul>
    </li>
    <li>✅ <strong>Test Management:</strong> Schedule and track driving tests (theory, vision, practical).</li>
    <li>✅ <strong>Application Types:</strong> Customizable application and test types with fees.</li>
  </ul>
  
  <h2 style="color: #0a66c2; font-size: 20px;">🔹 Technical Highlights:</h2>
  
  <ul style="padding-left: 20px;">
    <li>- WinForms for desktop application</li>
    <li>- SQL (Connect to Database using ADO.Net)</li>
    <li>- 3 tier architecture (Business Layer, Presentation Layer, DataAccess Layer)</li>
    <li>- Secure authentication with user sessions</li>
    <li>- Data validation and error handling</li>
  </ul>
